# Cartesian to Geodetic Coordinate Converter

### A Python-Based Geodetic Coordinate Transformation Tool

## Overview

This project focuses on the transformation of Earth-Centered, Earth-Fixed (ECEF) Cartesian coordinates (X, Y, Z) into geodetic coordinates (Latitude, Longitude, and Ellipsoidal Height) using Python.

The project combines principles of geodesy, computational mathematics and programming to demonstrate the application of software development in surveying and geospatial sciences.

## Project Objectives

- Understand Cartesian and geodetic coordinate systems.
- Implement coordinate transformation using Python.
- Apply mathematical and geodetic principles to coordinate conversion.
- Explore the use of programming in surveying and geospatial computation.

## Technologies Used

- Python
- Mathematical computation
- Geodetic coordinate systems
- WGS84 reference ellipsoid (planned default)

## Coordinate Systems

**Input:** ECEF Cartesian coordinates (X, Y, Z), expressed in metres.

**Output:**
- Geodetic Latitude (degrees)
- Geodetic Longitude (degrees)
- Ellipsoidal Height (metres)

## Methodology

The conversion uses the mathematical relationship between Earth-Centered, Earth-Fixed Cartesian coordinates and geodetic coordinates referenced to an ellipsoid.

The implementation will account for the selected ellipsoid's semi-major axis and flattening.
